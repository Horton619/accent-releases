# Accent

Downloads for **Accent**, a Mac app by Visual Entropy Productions that adds motion accents to stills.

**Install:** open the latest release under [Releases](https://github.com/Horton619/accent-releases/releases/latest), download `Accent-<version>-arm64.dmg`, and drag Accent to **Applications**. Open it from Applications; it can't update itself when it runs from the DMG or Downloads.

Requires a Mac with Apple Silicon (M1 or newer). Accent checks for updates on its own after launch.

This repository holds builds only.
